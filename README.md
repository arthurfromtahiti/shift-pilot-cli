# shift-pilot-cli

Pilote de test SHIFT/Paperclip — petit outil en ligne de commande calculant moyenne et médiane
d'un fichier CSV à une colonne de nombres.

## Usage

```
node bin/index.js data.csv
```

## Tests

```
npm test
```

La suite de tests fait référence : tout écart entre le comportement et les tests est une anomalie.
